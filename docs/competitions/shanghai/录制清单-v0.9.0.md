## 一、录前准备（约 10 分钟，先全部启动并自检）

### 1. 终端 A：启动纯 CRM（不要让它开 AI，它本来就没有）
```
uv run python examples/host_e_sales_crm/web_app.py
```
- 浏览器自动打开 http://127.0.0.1:8200 ，是**纯 CRM**（客户 / 订单 / 商机三个视图）。
- 录前先点页面上的"重置演示数据"，保证客户数、金额是初始值（5 客户 / ¥38,700）。
- 若浏览器没自动开，手动访问 8200。

### 2. 终端 B：启动灵动岛（接真实模型）
```
uv run python -m shell.desktop --live
```
- 桌面出现悬浮球（灵动岛）。确认项目根 `.env` 已配好模型（当前是 agnes-2.5-flash 免费段）。
- 想录得顺：第一笔用默认 `partial`（展示一次"批准"弹窗，体现安全），后面在齿轮里切到"无需审批"。
  - 也可直接全程免审批：`uv run python -m shell.desktop --live --permission auto`。
- 全局热键 **Ctrl+Alt+Y**：在任何软件里按下，都会把灵动岛拉到前台并展开。

### 3. 可选：两个真实开源软件（用于"通用性"佐证段）

- Actual Budget（记账）：`uv run python examples/host_j_actual/web_app.py` → http://127.0.0.1:8240
- 时间紧可只录主秀（CRM），Mealie 保留，Actual 取舍。

### 4. 录屏与窗口
- 录屏：Win+G 或 OBS，1080p。
- 浏览器窗口拉到屏幕约 70% 靠左，给灵动岛浮窗在右侧留位置。
- 再开：① Gitee 仓库页 https://gitee.com/Gi-Tuu/yai-agent-core ；② VS Code 打开

## 三、第 7 段：已在真机验证过的话术（照念即可，保证可复现）

这些话术在当前 main + agnes-2.5-flash + 8200 上已端到端跑通，跨进程真实写库、读回、按需能力都正常。

1. **写客户（展示授权 + 自动刷新）**
   - 输入：`请新增一位客户，姓名叫"林晚"，公司是"晚星贸易"，等级普通。`
   - 预期：路由 `react` → 调 `add_customer`（partial 挡位弹批准，点允许）→ 客户列表自动轮询出现"林晚"。
2. **录订单 / 搜索（展示写后读）**
   - 输入：`给林晚录一笔软件订单，金额 20000 元，区域华南。`
   - 输入：`搜一下重点客户，看看林晚的档案。`
   - 预期：订单视图出现新订单；搜索能查到档案。
3. **按需能力（展示"发现工具"，这是亮点，务必录）**
   - 输入：`广州明天要去外勤，需要带伞吗？`
   - 预期：触发"按需发现"，调用 `get_visit_weather` → 回答"阵雨，建议带伞"。
   - 输入：`给客户报 10000 元的价，按 13% 增值税，价税合计多少？`
   - 预期：调用 `calc_quote_with_tax` → "不含税 10000，税 1300，价税合计 11300"。

> 录完务必在 CRM 点"重置演示数据"，把林晚和测试订单清掉，避免后面段落数据不一致。

## 四、灵动岛操作要点（避免录制时找不到）

- **呼出/展开**：点悬浮球，或在任意软件按 Ctrl+Alt+Y。
- **收回成球**：鼠标移出面板后会自动收回（默认开启，约 150ms 延迟）；齿轮里可关"自动收回"。
- **选专员**：面板左侧手风琴，点专员名展开；销售员显示就绪需要 8200 CRM 已启动（启动顺序：先 CRM，再在岛上选销售）。
- **权限三档**：齿轮 → 审批模式。
  - 全部审批：每个工具都问；
  - 部分审批（默认）：读类自动放行，写操作问；
  - 无需审批：全自动，录屏最顺，但少了安全展示。
- **Core 开关**：齿轮里可整体停用 Core（停用后专员只走离线演示）。
- **球位置**：拖动后记忆；单实例已做，重复启动只会展开已有气泡，不会开两个。

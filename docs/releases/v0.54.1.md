# v0.54.1 — 真实运行验证

> **English summary**: v0.54.1 fixes the Go example's `go run` working-directory issue found by
> actually running it (now `go -C <example> run .`), and records real Chromium, Windows UIA and
> API-concurrency verification evidence.

v0.54.1 是审计后的“真实验证”补丁：不只跑离线测试，还跑真实浏览器、真实 Windows 桌面和 Go 示例。

## 1. Go 示例真实运行修复

- 真实运行发现：在仓库根执行 `go run ./examples/host_o_go_mcp` 会报
  `cannot find main module`（嵌套 `go.mod` 不会被当前目录继承）；
- 修复：`go -C <example_dir> run .`；
- 用临时下载的 **Go 1.22.12** 实跑通过：`tools: ['lookup_order']`、最终答案正常。

## 2. 真实 Chromium

- `scripts/browser_smoke.py --json`：通过；11 条 receipts，origin gate 拒绝错误来源，
  stale ref 被拒绝；
- `scripts/browser_provider_task_smoke.py`：通过；`verification.status=verified_success`、
  `receipt_chain_ok=true`，页面真实文本包含完成结果。

## 3. 真实 Windows UIA

- `scripts/windows_uia_smoke.py --json`：通过（UIA invoke 触发按钮回调）；
- `scripts/windows_real_apps_smoke.py`：对 `charmap.exe` 通过 12 项——窗口发现、
  文本输入/校验、按钮、焦点、下拉选择、接管、过期 ref、非白名单窗口拒绝。

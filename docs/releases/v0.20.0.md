# YAI Agent Core v0.20.0

> 发布日期：2026-10-24 · 范围：`v0.19.0` 之后的 PR（#89）· 许可证：MIT
> 本页是 GitHub Release 正文源稿；逐条变更清单以 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md) 的 `[v0.20.0]` 小节为准。

**这一版重做桌面灵动岛的视觉与信息结构：Optical Obsidian + Braun Signal Orange，并把胶囊、工作台、HITL、VAULT、MEMORY 排成设计稿的形状。**

内核 API、SPI 与依赖均未变化；这次只改 `shell/desktop/`、截图与文档。

---

## 一、胶囊：从“状态点”变成可读的活动条

- `01/SALES` 编号 + 当前任务摘要 + `OPEN` + 收起箭头；
- 左侧四态星云/行星，不再用波形条和状态点；
- 星云渐变改为 QML 圆角矩形，Canvas 只画粒子/轨道，修掉胶囊左端的直角矩形；
- 壳层保持不透明，避免桌面其他窗口的文字透进对话。

## 二、工作台：按设计稿重排

- 顶栏：`YAI.CORE · offline/live · 0-deps` + `VAULT [n]` + `MEM [n]` + 设置 + 收起；
- 专员索引：`01 销售专员 / 02 仓库专员 / 03 笔记专员 / 04 陪伴专员`，活动项白底黑字；
- 审批卡：`HITL.GATE // 写操作冻结待批` + `RISK: HIGH` + 参数/预览 + `[APPROVE] 批准放行` / `[REJECT] 拒绝阻断`；
- 推理区：`TRACE // 推理过程 N 步` 折叠行、组合工具链路、对话气泡；
- 输入：`>` 前缀 + “输入自然语言或指令调配宿主函数…” + `RUN`；
- `VAULT` / `MEMORY`：全屏面板，标题、互切与 `[ESC] 返回` 对齐设计稿。

## 三、四态星云与性能

`NebulaOrbCanvas.qml` 在球、胶囊与面板顶栏共用：

- `idle` 向右漂散；`working` 顺时针行星；`complete` 冲击波；`frozen` 减速静止；
- 空闲/完成 20fps、工作 60fps、冻结减速到 0 后停画；
- 实测胶囊待命约占单核 **6.2%**，不是满屏重绘。

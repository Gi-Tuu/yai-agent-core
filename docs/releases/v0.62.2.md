# v0.62.2 — AstStream 状态对象

> **English summary**: v0.62.2 is a patch on the 0.62 line. `astream` moves to
> `kernel/astream.py` with an `AstStreamState` object; `kernel/loop.py` is now 37.6KB.

v0.62.2 继续 0.62.X 结构重构线，不抬 minor。

## 1. AstStream 状态对象

新增 `src/yai_core/kernel/astream.py`：

- `AstStreamState`：`final_text` / `run_status` / `run_error_text` / `outcome` / `tier_counts`；
- `run_astream(loop, ...)`：原 `astream` 主链（路由、缺口发现、clarify、plan/react、
  预算熔断、历史落盘、DONE）；
- `AgentLoop.astream` 只做 async generator 薄委托，保留原返回类型注解。

`kernel/loop.py` 48.0KB → **37.6KB**。

## 2. 兼容性

- `_SYSTEM_TEMPLATE`、`_BUDGET_SCOPE_LABELS`、`_BUDGET_STOP_TEXT` 随 astream 迁移；
  `loop` 保留 re-export，测试 `from yai_core.kernel.loop import _SYSTEM_TEMPLATE` 仍可用；
- 事件顺序、DONE 字段、预算熔断、澄清递归语义不变。

## 3. 验证

- 全量门禁：2,550 项 / 2,545 passed / 5 skipped / 92.97%；
- code tools / loop / runtime contract / review fixes 回归通过；
- sdist 打包测试通过。

# v0.60.0 — 巨型模块拆分（第二批）

> **English summary**: v0.60.0 continues the behavior-preserving split: loop protocol helpers,
> executor result/timeout helpers, and composite execution move into focused modules with
> compatibility re-exports.

v0.60.0 继续拆第一批剩下的耦合点；不改变行为。

## 1. 拆分结果

### `kernel/loop.py` 70.2KB → 69.4KB

- `src/yai_core/kernel/protocol.py`：伪工具调用识别、模型阶段标记、工具输出不可信包裹。
- 仍保留 `AgentLoop`；`_react_cycle` / 规划等主体未动。

### `tools/executor.py` 63.5KB → 53.5KB

- `src/yai_core/tools/result.py`：结果上界、参数指纹、超时辅助、超时异常；
- `src/yai_core/tools/composite.py`：组合工具逐步执行（权限链、预算、超时、收据）；
- 执行器方法只做薄委托；旧导入路径保持。

## 2. 兼容性

```python
from yai_core.tools.executor import ToolTimeoutError, bound_tool_result
from yai_core.kernel.loop import _looks_like_raw_tool_call, wrap_tool_output
```

以上路径仍可用；实现位置变化不影响行为。

## 3. 验证

- 全量门禁：2,550 项 / 2,545 passed / 5 skipped / 92.96%；
- loop / composite / executor / timeout 回归通过；
- sdist 打包测试通过。

## 4. 下一批

- `kernel/loop.py` 的 `_react_cycle` / 规划 / schema focus 仍耦合 `AgentLoop`；
- `sidecar/native_bridge.py`（50KB）的 framing/config 可拆，但需先处理 `BridgeError` 依赖；
- 不做只搬文件的重构，先抽状态对象再拆。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

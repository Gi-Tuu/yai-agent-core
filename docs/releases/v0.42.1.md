# v0.42.1 — Box 电脑操作验收

> **English summary**: v0.42.1 adds `examples/host_box_mcp/acceptance.py`, a real-machine A–D
> acceptance for driving the Box cloud desktop over MCP: read screen, GUI typing verified by
> `read_file`, browser form write verified by `browser_read`, and cleanup. All checks pass.

v0.42.1 把 Box 接入从「能连上」推进到「能验收」：新增 A–D 真机验收脚本。

## 重点

- **A 读**：`box_status` = running（`sbxdesk:v22`）；`computer_state` 读到 Xfce 窗口；
- **B GUI 写**：`computer_act` 启动终端并键入 `echo box-gui-ok > /workspace/gui-proof.txt`，
  `read_file` 读回 `box-gui-ok`——证明屏幕输入真的落到了文件；
- **C 浏览器写**：`write_file` 建本地表单 → `browser_navigate` → `browser_type` /
  `browser_click` → `browser_read` 输出 `hello YAI`；
- **D 清理**：`shell` 删除验收文件。
- 复现：`uv run python examples/host_box_mcp/acceptance.py`（本机五项全 PASS）。

## 边界

- 这是「YAI 作为 MCP Client 驱动 Box 云桌面」的验收，**不是 Side Panel 扩展**验收；
- 浏览器窗口按 MCP 会话隔离，C 必须在同一个 `McpToolBridge` 连接内；
- 真机脚本不进 CI（Box 是外部云服务）。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

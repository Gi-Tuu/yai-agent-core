# v0.62.7 — Sidecar 入口

> **English summary**: v0.62.7 adds the installable `yai-core-server` sidecar entrypoint
> (`python -m yai_core.server`), with 0-tool read-only default, opt-in writes and a
> service-key `/v1/shutdown`. Verified on a clean Python 3.14.2 venv.

v0.62.7 是 M8 的前置：让 Core 以 wheel 形式被 AMBRACE 作为 sidecar 拉起，不依赖
`scripts/serve_example.py`。

## 1. 入口

```powershell
pip install "yai-agent-core[sidecar]==0.62.7"
$env:YAI_SERVICE_KEY="<per-install random>"
$env:OPENAI_API_KEY="..."
$env:OPENAI_BASE_URL="..."
$env:LLM_MODEL="..."
$env:OPENAPI_SPEC_URL="http://127.0.0.1:8000/openapi.json"
$env:OPENAPI_BASE_URL="http://127.0.0.1:8000"
$env:OPENAPI_AUTH_TOKEN="<AMBRACE_SERVICE_TOKEN>"
$env:OPENAPI_ALLOW_WRITES="false"
yai-core-server --host 127.0.0.1 --port 8001
```

或 `python -m yai_core.server --host 127.0.0.1 --port 8001`。

## 2. 端点与语义

| 端点 | 说明 |
|---|---|
| `GET /health` | liveness |
| `GET /readyz` | 应用就绪；允许 0 工具 |
| `GET /v1/tools` | 当前工具；默认只读时 **0** |
| `POST /v1/agent/run` | 任务；`run_id` 需 `X-Service-Key` |
| `POST /v1/agent/runs/{id}/cancel` | 取消；需 `X-Service-Key` |
| `POST /v1/shutdown` | 202 后 `should_exit`；需 `X-Service-Key`，仅 server 模式注册 |

## 3. 安全默认

- `OPENAPI_ALLOW_WRITES=false` → OpenAPI discovery 只注册 GET/HEAD，AMBRACE 四个 POST 工具为 **0**；
  这是合法的安全默认，不是挂载失败。
- 显式 `OPENAPI_ALLOW_WRITES=true` 才挂写工具。
- `X-Service-Key` 未配置时，run_id/cancel/shutdown 一律 403。
- 只绑 `127.0.0.1`；不提供公网监听默认。

## 4. 模型

Sidecar 需要模型配置：`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `LLM_MODEL`。
`YAI_SIDECAR_OFFLINE=1` 仅用于 health/smoke，不是生产模式。

## 5. 验证

- Python 3.14.2 干净 venv：`pip install -e '.[sidecar]'` 成功；
- `yai-core-server` 启动，health 200、`/v1/tools` 0、service-key shutdown 202、进程 exit 0；
- M8 入口测试：默认 0 工具、opt-in OpenAPI 工具、无模型拒绝启动；
- 全量门禁。

## 6. 边界

- 单容器双进程不作为推荐；AMBRACE 侧默认 compose 两服务或 Windows 子进程。
- `OPENAPI_ALLOW_WRITES=false` 时设备工具不可用，UI 需提示用户开启。
- 本版只做入口，不包含 AMBRACE launcher/安装器。

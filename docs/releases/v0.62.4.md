# v0.62.4 — 审批预览 + 工具准入拆分

> **English summary**: v0.62.4 is a patch on the 0.62 line. Preview generation/recheck and the
> admission gate (native approval, egress, arguments, rate check) move out of `executor.py`.

v0.62.4 继续 0.62.X 结构重构线。

## 1. 审批预览

新增 `src/yai_core/tools/preview.py`：

- `_PreviewError`；
- `preview_or_reject`：生成审批预览，失败按失败关闭记收据；
- `recheck_approved_preview`：审批后复核预览 token；
- `approved_preview_failure`：只返回原因/标记，事件与收据归调用方。

## 2. 工具准入

新增 `src/yai_core/tools/admission.py`：

- `_native_approval`：把 `governance.approval` 数据声明折成 `GateDecision`；
- `_tighten`：函数级闸 + 数据级闸取更严；
- `check_admission`：gate → egress → 参数校验 → 频率“只查不扣”；
  - 频率配额仍在授权通过后记账，避免被拒绝调用耗尽配额。

`tools/executor.py` 46.7KB → **41.0KB**。

## 3. 验证

- 全量门禁：2,550 项 / 2,545 passed / 5 skipped / 92.98%；
- native approval / execution policy / egress / preview 回归通过；
- sdist 打包测试通过。

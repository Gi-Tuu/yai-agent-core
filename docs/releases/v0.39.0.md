# v0.39.0 — AG-UI 1.0 适配器

> **English summary**: v0.39.0 adds an AG-UI 1.0 adapter that translates YAI's single event
> stream into standard SSE frontend events (`RUN_STARTED` / `TEXT_MESSAGE_*` / `TOOL_CALL_*` /
> `RUN_FINISHED` / `RUN_ERROR`, everything else as `CUSTOM`), plus a FastAPI example host and a
> bilingual guide. The kernel and its event stream are unchanged.

v0.39.0 给"唯一事件流"接上一个标准前端出口：**AG-UI 1.0**。
前端（React / CopilotKit / `@ag-ui/client`）可以直接连 YAI，不需要私有协议或 QML。

## 重点

- **`yai_core.integrations.ag_ui`**：
  - `AgUiTranslator` 状态机：`RUN_STARTED`、`TEXT_MESSAGE_{START,CONTENT,END}`、
    `TOOL_CALL_{START,ARGS,END,RESULT}`、`RUN_FINISHED`、`RUN_ERROR`；
  - 其余 YAI 事件（strategy_selected / plan_created / permission_asked / clarify_requested …）
    保留为 `CUSTOM`（`name="yai.<type>"`, `value=` 原始载荷），不丢信息、不假装语义；
  - `encode_sse()` / `stream_sse()`：AG-UI 1.0 HTTP+SSE 帧（LF、单个 `data:` 完整 JSON）。
- **示例宿主**：`examples/host_ag_ui_sse/`，FastAPI `POST /agent` → `text/event-stream`，
  离线 `ScriptedModel`；中英 README + curl 示例。
- **文档**：`docs/guides/ag-ui.md` / `.en.md`（映射表、SSE 格式、示例、边界）；
  mkdocs 中英导航、BILINGUAL 配对、IMPLEMENTATION_STATUS 证据行、README 示例表、DOCUMENT_MAP。

## 升级指引

- 无 breaking：新增可选集成，不新增依赖（适配器只用标准库；示例需要 `[server]` extra）。
- 事件流本身未变：`AgentCore.astream` 仍是唯一出口。

## 验证

- 全量门禁通过：**2485 项收集 / 2 480 passed / 5 skipped**，覆盖率 93.17%；
- `tests/test_ag_ui_adapter.py` 10 例：生命周期、文本消息、tool call 关联、失败 tool result、
  CUSTOM 映射、SSE 单帧、错误终止幂等、FastAPI TestClient 示例宿主；
- 中英指南与 BILINGUAL 配对守卫、docs 站导航/链接守卫、sdist 链接完整性均通过。

## 明确边界

- **非 token 级流式**：`model_message` 是完整文本，适配器一次 `CONTENT` 发出；
  逐 token 需要内核模型层暴露增量事件（不在本版范围）。
- **tool result 是受限预览**：`preview` 是内核已截断的结果，不是完整输出。
- **approval / clarify 未接 AG-UI interrupt/resume**：目前是 `CUSTOM` 事件。
- **不发 STATE_SNAPSHOT / MESSAGES_SNAPSHOT**：会话历史归宿主管理，适配器不复制。
- 未做真实 CopilotKit 前端端到端验收；本版验证的是映射、SSE 与示例宿主。

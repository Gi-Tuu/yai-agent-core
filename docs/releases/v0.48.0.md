# v0.48.0 — A2A 流式 + Registry 信任策略

> **English summary**: v0.48.0 adds A2A SSE streaming (`stream()` with `on_text`, used by `as_tool`
> when `A2AConfig(streaming=True)`) and a Registry trust policy (domain allowlist, repository/latest
> checks, a `verify_entry` signature/provenance hook, and rejection of registry-provided secret
> defaults). Host-layer only; the kernel stays unchanged.

v0.48.0 把 v0.47 的两个示例补上生产需要的两块：**流式**与**信任策略**。

## 1. A2A SSE 流式

- `A2AClient.stream(task, on_text=...)`：JSON-RPC `SendStreamingMessage` + SSE；
  - 处理 `task` / `artifactUpdate` / `statusUpdate` 帧，透传文本 chunk；
  - 聚合最终文本与终态；服务端返回 JSON 时自动回退非流式；
- `A2AConfig(streaming=True)` 时 `as_tool()` 也走流式聚合，内核仍只看到普通工具；
- 假 server 增加 SSE endpoint；7 例离线测试（chunk 回调、流式工具、轮询、Bearer 等）。

## 2. Registry 信任策略

- 新增 `RegistryPolicy`：
  - `allowed_domains`：精确/子域 allowlist；`allowed_repository_hosts` + `require_repository`；
  - `require_latest` / `require_active`；
  - `verify_entry(entry)`：签名/来源校验钩子（模块不内置密码学，宿主可接 sigstore/JWS）；
- `isSecret` header 的 registry 默认值**不再被信任**，必须由调用方显式提供；
- `search(policy=...)` 过滤、`build_config(policy=...)` 校验；
- CLI 默认要求 `--allow-domain`，`--allow-any-host` 才显式关闭；
- 8 例离线测试覆盖 allowlist、secret 默认、verifier、repository 要求。

## 验证

- 全量门禁：2,516 项 / 2,511 passed / 5 skipped，覆盖率 93.08%；
- 实测：`connect.py --allow-domain realtimeapi.ai --call list_feeds` 正常；
- A2A 假 server SSE 全部离线跑通。

## 边界

- A2A 适配器仍只支持文本/结构化 parts 的子集；push/OAuth/签名验证未做；
- `verify_entry` 是钩子，不提供内置签名格式或密钥管理；
- 示例是 host 层代码，不进 `src/yai_core/`。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

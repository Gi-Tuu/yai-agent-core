## 一、Node 宿主样例：真实跨语言链路

新增 `examples/host_l_sidecar_node/`，零依赖 Node（只用内置 `http` / `readline` /
`child_process`）：

```
Node 宿主进程
  ├─ HTTP 服务：GET /orders（OpenAPI 工具）+ POST /v1/chat/completions（mock 模型）
  ├─ stdio NDJSON 客户端：initialize / agent/run / 审批应答 / shutdown
  └─ 子进程：python -m yai_core.sidecar（AgentCore + OpenAPI Client）
```

它演示了完整的一条链路：

- Node 通过 OpenAPI 暴露自己的业务工具；
- sidecar 的 `approval/request` 反向发给 Node，Node 返回 `{"approved": true}`；
- 事件流从 `strategy_selected` 到 `done` 全部经 stdio 返回；
- 模型走本地 mock，不触外网、不需要 API Key。

```bash
YAI_PYTHON=.venv/Scripts/python.exe node examples/host_l_sidecar_node/host.mjs
# [host] 完成：订单共 2 笔：A001（¥100）、A002（¥200）。
```

## 二、CI 的 Sidecar 真实路径

默认 dev 环境没有 `[llm]` / `[mcp]`，因此 MCP 与 stdio 入口用例会被跳过。v0.17
新增独立 job：

- 安装 `dev + llm + mcp` extras；
- 跑全部 sidecar 协议用例；
- 再执行 Node 宿主样例。

这样“跨语言 + 审批 + MCP/OpenAPI”不再是只在本地手工验证的路径。

## 三、HostStateProvider 接进真实宿主

`examples/host_c_companion/run.py` 新增 `build_core()`：

```python
core = AgentCore.auto(capabilities, model, llm_router="auto")
core.register_state_provider("companion", capabilities.get_companion_profile)
```

当前档案（心情 / 能量 / 羁绊天数）在每次模型调用前作为瞬态 system 块注入：

- 默认任务“先查看小拥的状态……”不必再先调一次工具；
- 不写入对话历史、不占长期记忆、不参与压缩摘要；
- provider 失败只降级，不影响任务。

`tests/test_host_c_state.py` 钉住了“注入 + 不持久化 + 工具仍可用”。

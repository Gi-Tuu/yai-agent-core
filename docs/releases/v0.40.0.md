# v0.40.0 — LoCoMo 风格记忆基准

> **English summary**: v0.40.0 adds an offline, LoCoMo-style memory retrieval benchmark
> (`benchmarks/memory/locomo_bench.py`): 10 multi-session conversations / 5,882 turns / 1,986 QA,
> one vault per conversation, dedupe disabled, synchronous lexical recall only. On this CPU:
> Recall@5 0.3482, Recall@10 0.4163, MRR 0.2927. The dataset is downloaded from upstream (not
> redistributed) and verified by SHA-256; a synthetic fixture keeps CI offline.

v0.40.0 补上"标准口径"的记忆检索数字：**LoCoMo 风格离线基准**。
它不引入 embedder、不调 LLM、不联网，只量 MemoryVault 的词法召回在标准多会话数据上的水平。

## 重点

- **`benchmarks/memory/locomo_bench.py`**：
  - 上游 LoCoMo：10 段多会话对话 / 5,882 轮 / 1,986 QA（多跳 / 时序 / 开放域 / 单跳 / 对抗）；
  - 每段对话独立建库；每轮一条 note（`[dia_id] speaker: text`，`tags=[dia_id]`）；
  - **关闭去重**：基准要保证每个证据 id 都可被检索到（去重质量是另一个问题）；
  - 指标：Recall@5 / Recall@10 / MRR + 分类别 + 耗时；
  - 1,973 / 1,986 QA 可评估（13 条证据缺失跳过）。
- **可复现**：`--download` 从上游拉取并校验大小 / SHA-256；数据集**不随仓库分发**
  （上游 NOASSERTION 许可，再分发前自行核对）。
- **测试**：`tests/test_locomo_bench.py` 5 例（合成 fixture、CLI JSON、缺失数据可操作错误、指标）；
  真实数据集 2.6 秒跑完（本机 CPU）。

## 升级指引

- 无 breaking：只新增基准脚本与文档；内核依赖仍为空。
- 用法：`python benchmarks/memory/locomo_bench.py --download --json`。

## 明确边界

- **纯词法基线**，不是 LoCoMo 排行榜意义上的语义记忆系统；与 Mem0 / Zep 等
  （embedding + LLM 判定）的数字**不可直接比较**。
- 关闭去重是基准口径，不代表生产去重行为。
- 数据集不随包分发；上游许可为 NOASSERTION，再分发前需核对。
- 只跑 `MemoryVault.recall`（同步词法）；语义通道（Embedding SPI）未纳入该基准。

# v0.62.1 — ReAct / 幂等状态对象

> **English summary**: v0.62.1 is a patch on the 0.62 line. It extracts the ReAct loop into
> `run_react_cycle` with a `ReactState` object, and the idempotency cache into `IdempotencyCache`.
> No behavior change.

v0.62.1 是 0.62 线的补丁版：继续做结构拆分，不抬 minor。

## 1. ReAct 状态对象

新增 `src/yai_core/kernel/react.py`：

- `ReactState`：`had_failure` / `last_tier` / `terminal_messages` / `replanned`；
- `run_react_cycle(loop, ...)`：原 `_react_cycle` 主循环；
- `AgentLoop._react_cycle` 只做 async generator 薄委托。

`kernel/loop.py` 57.7KB → **49.0KB**。

## 2. 幂等状态对象

新增 `src/yai_core/tools/idempotency.py`：

- `_PermissionDependency` 权限依赖快照；
- `IdempotencyCache`：按 `(tool, key)` 的 LRU 缓存、参数指纹校验、依赖随条目淘汰；
- `ToolExecutor` 持有实例，`_cache_get/_cache_put` 移到对象内部。

`tools/executor.py` 53.5KB → **51.9KB**。

## 3. 验证

- 全量门禁：2,550 项 / 2,545 passed / 5 skipped / 92.96%；
- loop / receipt / execution / review fixes 回归通过；
- sdist 打包测试通过。

## 4. 版本策略

从本版起，连续结构重构走 **0.62.X patch 线**；只有行为/能力变化才考虑抬 minor。

## 5. 剩余

- `kernel/loop.py` 仍有 `astream` 主链（取消/锁/收尾），下一批抽 `AstStreamState`；
- `tools/executor.py` 的 `_lookup_cache` / 预览复核可继续收进状态对象；
- 依然不为了拆而拆：事件顺序、取消语义、收据链优先。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

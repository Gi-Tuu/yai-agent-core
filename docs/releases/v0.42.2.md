# v0.42.2 — CopilotKit demo 加固

> **English summary**: v0.42.2 hardens the CopilotKit demo: the example now performs a real
> `demo_fact` tool call (SSE includes `TOOL_CALL_*`), and a new GitHub Actions workflow runs
> `npm ci` + `npm run build` + a dist check only when the demo changes.

v0.42.2 给 CopilotKit demo 补上两块：**真实 tool call** 与 **前端构建 CI**。

## 重点

- **示例出现真实 tool call**：`examples/host_ag_ui_sse/` 用 `ScriptedModel` 先调用本地
  `demo_fact` 工具，再给最终回答；SSE 流包含
  `RUN_STARTED / TOOL_CALL_START / ARGS / END / RESULT / TEXT_MESSAGE_* / RUN_FINISHED`。
- **前端事件面板**：CopilotKit `App.jsx` 展示 `TOOL_CALL_*`；截图更新
  `docs/assets/copilotkit-demo.png`。
- **CI**：新增 `.github/workflows/copilotkit-demo.yml`，只在
  `examples/host_ag_ui_copilotkit/**` 或该工作流变化时触发，执行
  `npm ci` + `npm run build` + `test -f dist/index.html`。
- **测试**：`tests/test_ag_ui_adapter.py` 断言示例 SSE 含 tool call 事件与 `demo_fact`。

## 升级指引

- 无 breaking：只改示例与 CI；内核依赖仍为空。
- 运行方式不变：先起 `host_ag_ui_sse`，再 `cd examples/host_ag_ui_copilotkit && npm start`。

## 明确边界

- 示例仍是离线 `ScriptedModel`（非真实 LLM），只是多了一次真实工具调用；
- 事件面板的 `TOOL_CALL_*` 是 AG-UI 映射结果，不是前端工具执行；
- CI 只验证构建，不跑浏览器 E2E（本机 Chromium 实测并留截图）。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

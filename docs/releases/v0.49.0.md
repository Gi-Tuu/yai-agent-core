# v0.49.0 — A2A OAuth/push + Registry digest + 社区项

> **English summary**: v0.49.0 adds A2A client-credentials OAuth and push-config methods, built-in
> Registry digest pinning, a zero-dependency Go MCP example (#168), an offscreen CROSS-CORE QML test
> (#169), and a local real-machine regression section in CONTRIBUTING (#170).

v0.49.0 是一批"边界与社区"更新：A2A 认证/推送、Registry 完整性、Go 示例、QML 测试与真机文档。

## 1. A2A OAuth2 + push

- `A2AOAuth2` client-credentials：token 获取、缓存、提前 30s 刷新、Bearer 注入；
- push 配置：`create_push_config` / `list_push_configs` / `delete_push_config`
  （只注册/查询/删除，webhook 接收端由宿主实现）；
- 9 例离线测试（SSE、OAuth、push、轮询、Bearer 等）。

## 2. Registry 内置 digest pin

- `RegistryPolicy.pinned_digests=(("server/name", sha256),)`：对 registry 原始条目做
  canonical JSON（sort_keys、紧凑分隔符）SHA-256；
- `require_pinned=True` 拒绝所有未固定条目；
- 明确边界：digest 是**完整性**，不是身份；registry v0 没有统一签名字段，
  `verify_entry` 钩子仍保留给 sigstore/JWS；
- 9 例离线测试。

## 3. 社区项

  无 Go 时退出码 2 并给安装指引；Go 代码未在本机编译（无 Go 环境），README 已注明。

  `crossCoreSummary` / `crossCoreHasFailure` / `crossCoreColor`，delegate 逻辑不变。

## 边界

- A2A OAuth 只实现 client credentials；authorization-code/device flow 未做；
- push 只做配置管理，不实现公网 webhook 接收；
- Registry digest 不是签名；签名仍需宿主接钩子；
- Go 代码未经本机编译验证。

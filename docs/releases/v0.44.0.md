# v0.44.0 — LoCoMo 端到端记忆问答

> **English summary**: v0.44.0 connects BGE-M3 recall to answer generation on LoCoMo: one vault per
> conversation, bge-m3 top-5 excerpts in the prompt, a real model answering only from those excerpts,
> and SQuAD F1/EM scoring. On 1,973 QA (zero failures), answerable categories 1–4 (n=1,527) reach
> Recall@5 0.5568 / F1 0.3480 / EM 0.1932; total runtime 368s (local CPU + API).

v0.44.0 回答下一个问题：**召回接上回答后，LoCoMo 还能得多少分？**

## 结果（1,973 QA，0 失败）

| 范围 | n | Recall@5 | F1 | EM |
|---|---:|---:|---:|---:|
| 全部（含对抗类） | 1,973 | 0.5067 | 0.2701 | 0.1500 |
| **可回答（cat 1–4）** | **1,527** | **0.5568** | **0.3480** | **0.1932** |

分类别：

| 类别 | n | Recall@5 | F1 | EM |
|---|---:|---:|---:|---:|
| 1 多跳 | 278 | .2886 | .2789 | .0647 |
| 2 时序 | 320 | .6901 | .1017 | .0156 |
| 3 开放域 | 89 | .2984 | .1302 | .0674 |
| 4 单跳 | 840 | .6222 | .4878 | .3167 |
| 5 对抗 | 446 | .3352 | .0031 | .0022 |

- 单跳类最好（F1 .488）；时序类召回高但 F1 低（gold 是绝对日期，模型常答“Last year”）；
- 对抗类 gold 多为空/“Not mentioned”，F1 不具解释性，**不计入可回答汇总**。

## 实现

- `benchmarks/memory/locomo_e2e_bench.py`：
  - bge-m3 语义 top-5 片段拼进 prompt，模型只依据片段回答；
  - SQuAD token F1 + Exact Match；同时报告检索 Recall@k；
  - 支持 `--samples` / `--limit-qa` / `--retrieval` / `--predictions` / `--concurrency`；
  - 真实模型走 OpenAI 兼容 provider，Key 从本地 `.env` 读取。
- `tests/test_locomo_e2e_bench.py`：假模型/假嵌入/F1 三例离线回归，不需要 Key。
- 文档：memory-evaluation 中英、bench README、IMPLEMENTATION_STATUS、CHANGELOG。

## 实测环境

- 模型：`deepseek-v4.1-flash-1017`（OpenAI 兼容）；
- 本机 CPU 8 线程 embed 88.5s；回答 261.2s（并发 8）；总 368s；
- 1,973/1,973 成功，无重试失败。

## 明确边界

- F1/EM 是词法重叠，不判语义等价；没有接 LLM judge；
- 单模型、单次运行；检索错误会直接传导到回答；
- LoCoMo 数据集不随包分发；Key 只在本地 `.env`，不进仓库；
- 对抗类（cat 5）单列为参考，不纳入可回答汇总。

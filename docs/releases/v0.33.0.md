# v0.33.0 — 父子核生态落地

v0.33.0 补齐父子核的生态落地三件：**专员桥**、**usage / token 预算**、**两个可安装子核示例**。
内核依赖与公开契约不变。

## 重点

- **专员桥（`shell/federation/specialists.py`）**：`build_specialist_child()` 把一个"应用对象"
  （桌面灵动岛专员的形态）的公开方法内省成子核工具；`attach_specialists()` 一行把多个专员
  接入父核。Qt 面板本身的接线仍属宿主侧（headless 桥）。
- **usage / token 预算**：子核工具结果可带 `{"usage": {...}}`，父核按 edge 聚合进
  `edge_stats()`（`tokens` / `usage`）；`register_child(max_tokens=...)` 超限抛
  `edge_token_budget_exceeded`（失败关闭，不静默超支）。
- **两个可安装子核**：`examples/child_cores/` 提供笔记 / 计算器两个独立子产品
  （各自 `ChildServer` + 发现文件），`hub_demo.py` 用 `ManagedChild` 同时托管两个进程并跨核调用。

## 升级指引

- 无 breaking：新增宿主层能力；内核依赖仍为空、公开契约不变。
- usage 是**可选约定**：不回报 usage 的子核照常工作（只统计调用/耗时/失败）。

## 验证

- 新增 `tests/test_federation_specialists.py` 5 例（专员对象内省 / 多专员接入 /
  usage 聚合与 token 预算 / 两子核双进程 demo）；联邦测试合计 32 例。
- `hub_demo.py` 实跑：父核工具 `notes__*` / `calc__*`，跨核调用后读回子核状态
  （笔记内容与 `12+30=42` 历史）。
- 全量门禁通过；CI 四平台矩阵 + sdist + docs build 全绿。

## 明确边界

- 专员桥是 headless 的：Qt/QML 面板接线仍由宿主完成，本版不宣称"灵动岛已支持跨核调用"。
- 跨核事务、守护式自动重启、manifest 服务端主动推送仍未实现。
- token 预算按子核**回报的 usage** 计；不回报 usage 的子核只能按调用次数预算。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

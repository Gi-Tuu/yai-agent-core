> 发布正文源稿。GitHub Release 会带 cosign 签名资产（wheel/sdist 及各 .sig/.pem/.sigstore）、

## 这一版是什么

三个 feat + 一次文档整理。**没有内核 API 变更**，唯一的破坏性改动是部署验证端点改名。

## 四条主线

1. **一条命令跑完治理闭环**（`python scripts/demo_governance_loop.py`）
   离线脚本模型发起一次退款调用 → 内核在参数级审批处拦下并**冻结参数** → 批准才执行、
   拒绝零副作用 → 全过程写成可回查的 JSONL trace。`--refuse` 验证零副作用，`--trace`
   指定落盘路径，**退出码即断言**。参数取值只进 trace，不打到终端。

2. **一条命令跑完全部门禁**（`python scripts/check_all.py`）
   锁定文件 → Lint → 类型检查 → 版本与打包守卫 → 全量离线测试 + 覆盖率门禁 → 两宿主冒烟。
   任何一步失败立即停下并给出退出码；`--fast` 跳过全量测试，`--list` 只打印计划。

3. **能力与证据索引**（`docs/IMPLEMENTATION_STATUS.md`）
   把"已验证 / 已实现·未真机验证 / 明确不做"分三档列出，每条能力都给对应测试或实测证据与边界——
   README 回答"能做什么"，这份回答"做到了什么程度"。

4. **桌面星云粒子数可配置**（`ui/nebulaParticles`，默认 260）
   `NebulaOrbCanvas` 的粒子数改由 `particleCount` 属性驱动（收敛 24–1200），胶囊与面板顶栏
   两处都绑到 `workbench.nebulaParticles`。实测 260 → 520：仍是 60fps，但单核 CPU
   约 13.8% → 20.3%——粒子数是真成本，默认值保持与设计稿同源的 260。

## 升级

```bash
pip install --upgrade yai-agent-core   # 0.23.0
```

**破坏性改动**：部署验证端点由旧路径改为 `/.well-known/yai-verification.json`。
若你自建服务依赖旧路径，请同步修改；`/health` 与 `/v1/tools` 不变。

- **粒子数默认值未变**（260）：520 是个人偏好，通过 `ui/nebulaParticles` 覆盖。
- 线上实例的 `/v1/agent/run` 鉴权仍是待决项，本版未改。

# v0.30.0 — 有向父子核 Phase 3（生态运维）

v0.30.0 把父子核从"能跑"推到"能长期运维"：子核能力变了父核能收敛、每个 edge 有限额与统计、
子产品进程由宿主托管并在死亡时失败关闭。内核依旧零改动。

## 重点

- **manifest 热更新**：`handshake` / `tools.list` 带 `manifest_version`；父核 `refresh_child()`
  重新拉取并收敛暴露面（全集注册跟随新增/移除，显式子集保持子集）；未配置父核白名单时
  发**通配 grant**（`"*"`），子核热更新后无需重新握手。
- **每 edge 配额**：`ChildServer(edge_quota_per_minute=...)` 一分钟滑动窗口，超限
  `quota_exceeded` 失败关闭（不排队、不静默降级）。
- **父核预算与统计**：`register_child(max_calls=...)` 每 edge 调用上限；
  `edge_stats()` / `stats()` 记录 calls / failures / total_ms / last_error。
- **子核注销**：`unregister_child()` 同步移除父核暴露的工具，避免"能力已走、工具还在"。
- **进程托管**：`ManagedChild` 拉起子产品进程 → 等发现文件 → 连接；`ensure()` 在进程存活时
  重连，进程死亡后 `ChildUnavailable`；`stop()` 清理连接、进程与发现文件。
- **测试**：`tests/test_federation_ops.py` 8 例；联邦测试合计 27 例。

## 升级指引

- 无 breaking：新增宿主层能力；内核依赖仍为空、公开契约不变。
- 安全边界照实声明：同 OS 用户前提；发现文件权限与 token 只防同机其他用户/进程，
  **不防 root / 调试器 / 内存抓取**。

## 验证

- 2420 项测试收集、2415 passed / 5 skipped；内核行覆盖率 93.13%（门禁 90%）。
- 27 项联邦测试全绿（含进程内、IPC、进程托管与死亡失败关闭）。
- 全量门禁通过；CI 四平台矩阵 + docs build 全绿。

## 明确边界（后续批次）

token 级预算跨核聚合、跨核事务、守护式自动重启（进程死后由宿主决定）、服务端主动推送
manifest（当前父核主动 refresh）均未实现；桌面灵动岛接入与"可安装子核"示例仍在后续批次。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

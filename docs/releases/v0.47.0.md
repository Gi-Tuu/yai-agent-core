# v0.47.0 — A2A 宿主适配器 + Registry 接入

> **English summary**: v0.47.0 adds two runnable host-layer examples: a minimal A2A 1.0 adapter
> (remote agent → `ToolSpec`, offline fake server + a real AgentCore tool call, 5 offline tests) and
> an explicit MCP Registry connect/call example (`--name` required, `--call` opt-in; verified against
> `ai.realtimeapi/mcp`).

v0.47.0 把上一版的两份"定位"变成了可运行代码：A2A 宿主适配器与 Registry 显式接入。

## 1. A2A 宿主适配器

- `examples/host_a2a_adapter/`：
  - `a2a_client.py`：A2A 1.0 JSON-RPC 客户端（Agent Card / `SendMessage` / `GetTask`，
    文本/结构化 parts、Bearer token），`as_tool()` 包成 `ToolSpec`；
  - `fake_a2a_server.py`：离线假 server（Agent Card、SendMessage、GetTask、WORKING→COMPLETED）；
  - `demo.py`：假 server → ToolSpec → `AgentCore` + `ScriptedModel`，内核只看到普通工具调用。
- 边界：只支持非流式文本子集；HTTPS（loopback HTTP 仅本地）；远端输出按不可信数据；
  5 例离线测试覆盖 card、调用、轮询、Bearer 头、message 结果变体、HTTP 拒绝。

## 2. Registry 显式接入

- `examples/host_mcp_registry/connect.py`：
  - `--name` 必填，**不自动挑第一个并连接**；
  - 默认只列工具，加 `--call` 才调用；
  - 实测评测：`ai.realtimeapi/mcp` 列出 6 个工具，`list_feeds` 返回 feed 列表。

## 验证

- 全量门禁：2,510 项 / 2,505 passed / 5 skipped，覆盖率 93.15%；
- A2A 离线假 server + Registry 真实接入均跑通；中英文档与导航同步。

## 边界

- A2A 适配器是 host 层代码，**不进 `src/yai_core/`**；不支持流式/push/OAuth/签名验证；
- Registry 示例只读、显式选择；信任判断仍归宿主；
- 示例不随 CI 做外部网络测试（A2A 假 server 离线；Registry 实测为手动）。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

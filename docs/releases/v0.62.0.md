# v0.62.0 — AgentLoop 规划拆分

> **English summary**: v0.62.0 moves discovery, planning, schema-focus and tool-name parsing from
> `AgentLoop` into a `PlanningMixin`, reducing `kernel/loop.py` from 68.0KB to 58.9KB.

v0.62.0 继续结构拆分：把 `AgentLoop` 的规划/发现/schema 聚焦逻辑抽成 mixin。

## 1. 拆分结果

- `src/yai_core/kernel/planning.py`：`PlanningMixin`
  - `_discoverable_catalog`
  - `_discover_tools`
  - `_make_plan`
  - `_focus_tool_schemas`
  - `_parse_tool_names`
- `AgentLoop(PlanningMixin, MetaToolRuntime)` 继承；
- `kernel/loop.py` 68.0KB → **58.9KB**。

## 2. 兼容性

- 旧代码 `loop._make_plan(...)` / `loop._focus_tool_schemas(...)` 仍可用（继承方法）；
- 测试对 `inspect.isasyncgenfunction(AgentLoop._discover_tools)` 的断言保持成立；
- 行为、事件、顺序不变。

## 3. 验证

- 全量门禁：2,550 项 / 2,545 passed / 5 skipped / 92.94%；
- loop / tool catalog / runtime contract 回归通过；
- sdist 打包测试通过。

## 4. 剩余

- `kernel/loop.py` 仍有 `_react_cycle` / `astream` 主链；
- 下一步是抽 `ReAct` 迭代状态对象，而不是继续搬方法；
- 不为了拆而拆：保持事件顺序与取消语义优先。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

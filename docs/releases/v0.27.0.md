# v0.27.0 — Real-world Reliability & Integration

v0.27 不继续堆功能，而是让已有的浏览器 / 桌面执行能力在并发、异常、权限边界和用户环境中可信。

## 重点

- **数据完整性**：MemoryVault 锁超时改为 fail-closed（保留内存/dirty，可 `flush` 重试，不再无锁读改写）；Bridge 配置锁改为跨进程 OS 锁；Windows 瞬态 `os.replace` 冲突统一有界重试。
- **执行安全**：Browser/Desktop 安全 preset；特殊协议默认拒绝；修改性动作默认审批；Playwright 在加载前拦截未授权重定向。
- **执行路径边界**：ADR 0006 明确扩展只读当前页 vs 受控浏览器；受控浏览器真实 E2E 通过；当前标签页写操作 opt-in、逐次审批。
- **证据与 Key**：宿主 verifier 证据最终限幅；ADR 0007 明确本地 Key 明文边界与 SecretStore 方案（加密尚未实现）。
- **真实 Windows**：真实 `charmap.exe` UIA 12/12（含下拉选择、用户接管、旧引用拒绝）；第三方应用/UAC 仍未覆盖。
- **评测与分发**：114 条记忆/60 query，真实 BGE-M3 Recall@5 0.899、P50 28.9ms；10k 规模边界明确；Windows 便携安装器、固定扩展 ID、升级快照/回滚；MCP CDP 自动拉起/回退。

## 验证

- CI 全绿：Linux 3.11/3.12/3.13、Windows 3.13、CodeQL、fuzz、sdist、sidecar、eval、benchmark。
- 覆盖率 ≥90%；本地 `uv lock --check`、ruff、mypy、pytest、sdist build 通过。

## 明确边界

- 真实 Side Panel 的当前标签页写操作仍需人工按 `docs/evaluations/sidepanel-manual-acceptance.md` 验收。
- Chrome Web Store / Edge Add-ons 分发未做。
- 10,000 条记忆规模未达标；SecretStore 仅方案。

# v0.25.0 · Production Readiness

> 发布正文源稿。GitHub Release 带 cosign 签名资产 + SLSA provenance。

## 一句话

**没有新增炫酷功能——这一版把 YAI 从"功能完整的 Agent Core"推进到"生产环境可集成、可维护、可验证的 Agent Runtime"。**

## 五条主线

1. **复审 8 类加固（安全）**：组合工具中途熔断不再丢收据（异常携带部分事件、
   熔断收尾补发，收据链不缺环）；后置条件验证与缓存重放撤权复核统一用
   "过闸后的有效参数"单一快照；外发 URL 来源记录改在 JSON 序列化前按结构化
   结果进行；IDNA 有损映射不合并信任；迭代上限收尾的伪协议文本 fail-closed；
   路由学习去掉工具计数误判。**全部先离线复现、再修复、各带回归测试。**

2. **外发来源闸边界（B1）**：紧粘 CJK 的主机名截断（`https://evil.example即可`
   不再被编成另一个 xn-- 主机漏拦）；路径大小写不敏感匹配；非 ASCII 主机
   不再触发 UnicodeEncodeError；Markdown/HTML/JSON 包裹、大小写与 www 变体、
   并发任务隔离、事件字段防泄漏——10 个新用例。

3. **生产安全默认值（B2）**：默认 allow_all 配置发 `ProductionSafetyWarning`
   （行为零变化），新增生产权限指南与可运行示例；v0.26 弃用迁移路径草案已记。

4. **Sidecar 身份绑定（B3）+ ADR 0002**：initialize 绑定会话级可信 Subject 后，
   请求参数里的 subject 直接拒绝（防多租户身份伪造）；ADR 明确三层边界归属
   （网络接入=宿主、用户身份=宿主、工具执行授权=YAI）。

5. **可验证与可嵌入（B4/B6/B7/B8）**：AgentDojo 重复采样与多攻击循环 + 四分类
   指标 + 独立聚合模块；生产形态 FastAPI 宿主示例（12 要素、4 项端到端测试）；
   执行审计持久化边界文档；OTel 防敏感泄漏回归；ADR 0003（ACC 边界）；
   IMPLEMENTATION_STATUS 校准。

## 升级

```bash
pip install --upgrade yai-agent-core   # 0.25.0
```

**零破坏**：公开 API、SPI、事件契约、宿主集成方式不变；默认行为唯一的变化是
新增一条 `ProductionSafetyWarning`（见 docs/production-permissions.md）。

## 诚实边界

- "模型拒绝 vs 内核拦截"的评测区分需要改 agentdojo agent 接口签名——已列入路线图；
- 默认权限值未翻转（破坏性决策），迁移路径草案待拍板；
- 沙箱 worker 的 `exec` 是产品职责，静态扫描器的"代码注入"报告为形状误报，不修。

# v0.42.0 — Box by Simular 真机接入

> **English summary**: v0.42.0 verifies Box by Simular as an ordinary MCP server: the existing
> `McpToolBridge` connects with a personal `BOX_TOKEN` and registers 36 tools (`shell`,
> `browser_*`, `computer_*`, `gui_plan`, `box_*`). Real-machine smoke: `box_status: absent` →
> `box_ensure: running` → `shell` (Linux 6.8, `/workspace`) → `browser_navigate` to example.com.
> The key stays only in the ignored local `.env.local`; the script never prints it.

v0.42.0 把 Box by Simular 接进真实机器链路：**Box 只是一个普通 MCP Server**，
用现有 `McpToolBridge` + 个人 key 即可驱动云桌面 shell 与 Chrome。

## 重点

- **示例**：`examples/host_box_mcp/`
  - `McpServerConfig(alias="box", url="https://mcp.box.simular.ai/mcp", token_env="BOX_TOKEN")`；
  - 同一 bridge 注册 **36 个工具**：`shell` / `read_file` / `browser_navigate` /
    `browser_click` / `computer_act` / `gui_plan` / `box_status` / `box_ensure` 等；
  - `smoke.py` 做 status → ensure → shell → Chrome 冒烟，`--json` 可机读。
- **真机实测（2026-11-14）**：
  - `box_status`: `absent` → `box_ensure`: `running`（image `sbxdesk:v22`）；
  - `shell`: `hello-from-box` · `Linux 6.8.0-142-generic x86_64` · `/workspace`；
  - `browser_navigate` → `https://example.com`：`Page: Example Domain`。
- **安全**：个人 key 只存本地 `.env.local`（`.gitignore` 的 `*.local` 已覆盖），
  脚本不打印 token；`.env.example` 只加 `BOX_TOKEN=` 占位。

## 升级指引

- 无 breaking：只新增示例与文档；内核依赖仍为空。
- 前置：`uv sync --extra mcp`；在 <https://box.simular.ai/access> 创建个人 key。

## 明确边界

- Box Free 显示 `0 credits left`；本冒烟只用 box 的 shell/Chrome（YAI 使用宿主自己的模型），
  是否计费以 Box 账单页为准；
- 未做完整 Side Panel / 桌面 GUI 验收；
- Box 是外部云服务，真机脚本不进 CI（手动运行）；
- 个人 key 泄露请在 Access 页 Revoke。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

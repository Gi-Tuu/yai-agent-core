# v0.38.0 — MCP 2026 安全边界

> **English summary**: v0.38.0 aligns the MCP client with the stateless 2026-07-28 specification
> (`protocol_mode`), adds URL authentication (`headers` / `token_env`), and hardens against tool-description
> poisoning by sanitizing remote descriptions and offering a `trust_tool_descriptions=False` mode.
> Verified by a real local stateless HTTP regression (uvicorn). mcp extra is now `>=2.2`.

v0.38.0 把 MCP 集成对齐到 **2026-07-28 无会话规范**，并补上两件安全/接入能力：
**URL 鉴权头**与**远端工具描述投毒防护**。内核依赖仍为空，`[mcp]` extra 提升到 `>=2.2`。

## 重点

- **无会话协议**：`McpServerConfig.protocol_mode`（`auto` / `legacy` / 版本串）透传给 SDK v2.2；
  `auto` 默认先 `discover`、失败回退旧 `initialize` 握手。2026-07-28 起协议级 `initialize` 与
  `Mcp-Session-Id` 已移除，Streamable HTTP 成为无状态 HTTP 工作负载。
- **URL 鉴权**：`headers` 直接加 HTTP 头；`token_env` 自动拼 `Authorization: Bearer <token>`
  （显式 Authorization 优先；缺环境变量给可操作错误）。stdio / 内存形态不允许 headers。
- **工具描述投毒防护**：远端 `tool.description` 注册前经 `sanitize_untrusted_text()`：
  去控制字符 / 零宽字符 / 双向覆盖符，折叠空白，按 `max_description_chars`（默认 1000）截断；
  `trust_tool_descriptions=False` 时**完全不把远端描述喂给模型**（只保留工具名 + schema）。
- **证据**：`tests/test_mcp_security.py` 启动真实本地 uvicorn stateless HTTP server，
  以 `protocol_mode="2026-07-28"` 完成 `tools/list` / `tools/call`，并断言
  `Authorization: Bearer test-token` 确实到达 server。

## 升级指引

- `[mcp]` extra 从 `mcp>=2.0` 提升到 `mcp>=2.2`（`mode=` 参数与 2026-07 支持需要）；
  `uv sync --extra mcp` / `pip install "yai-agent-core[mcp]"` 会自动升级。
- 默认行为不变：`protocol_mode="auto"`、`trust_tool_descriptions=True`（描述会被净化，但内容保留）；
  高风险环境可显式关掉远端描述。

## 验证

- 全量门禁通过：**2475 项收集 / 2 470 passed / 5 skipped**，覆盖率 **93.19%**（门禁 90%）；
- 新增 10 项 MCP 安全回归 + 7 项 hygiene 单测；
- 真实本地 HTTP（uvicorn stateless）验证无会话连接、工具调用与鉴权头；
- `uv lock --check` 通过（锁文件仅更新 mcp specifier）。

## 明确边界

- 描述净化只做**字符层**（控制/零宽/双向/长度），**不做语义指令检测**——语义检测误报高、
  也挡不住改写；真正的信任边界在宿主的 `trust_tool_descriptions` / 策略层。
- 无会话兼容由 MCP SDK v2.2 实现；本版只验证「客户端 + 本地 stateless server」这条链路。
- 尚未接 Box 等需要 OAuth/个人 key 的远程 Server（`headers`/`token_env` 已就绪，待真机验证）。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

# v0.62.5 — Native Bridge 配置拆分

> **English summary**: v0.62.5 is a patch on the 0.62 line. Bridge config, origin validation,
> atomic config writes and locking move to `bridge_config.py`; `native_bridge.py` is now 33.6KB.

v0.62.5 继续 0.62.X 结构重构线。

## 1. 拆分结果

`src/yai_core/sidecar/native_bridge.py`：44.0KB → **33.6KB**

新增 `src/yai_core/sidecar/bridge_config.py`：

- `BridgeConfig`（allowed_origins / initialize_params / max_task_chars / max_message_bytes /
  sidecar_command）；
- `_normalize_origin`、`mask_api_key`、`masked_model`；
- `config_backup_path` / `config_lock_path` / `bridge_config_lock`；
- `_atomic_write_bytes` / `atomic_write_json`；
- `load_bridge_config` / `default_config_path` / `default_log_path` / `resolve_config_path`。

`ConfigLockError` 与 `_try_lock_fd` / `_unlock_fd` 移到 `bridge_errors.py`。

## 2. 兼容性

```python
from yai_core.sidecar.native_bridge import (
    BridgeConfig, load_bridge_config, default_config_path,
    config_lock_path, bridge_config_lock, ConfigLockError,
)
```

旧路径仍可用；配置格式、锁语义、脱敏行为未变。

- native bridge / bridge config 测试通过；

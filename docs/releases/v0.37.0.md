# v0.37.0 — 双语国际化 / 认领流程 / 社区示例

> **English summary**: v0.37.0 adds a good-first-issue claiming flow (`claimed` label + issue
> template), completes 30 bilingual documentation pairs (homepage, capability index, guides,
> evaluations and ADRs, enforced by tests), and ships an offline OpenAPI 3.1 example contributed by
> the community. No kernel API or dependency changes.

v0.37.0 是"走向国际 + 社区协作"批次：把国际面文档补齐英文版并加防回退守卫，落成 good-first
认领流程，合并了社区贡献的 OpenAPI 3.1 离线示例。内核依赖与公开契约不变。

## 重点

- **good first issue 认领流程**：新增 `claimed` 标签与 `good_first_task.yml` 模板；
  `CONTRIBUTING` 中英明确"先评论认领 → 维护者确认加 `claimed` → 7 天无进展释放"。
  外部贡献者不能被 assign，用标签替代。
- **国际面双语文档（30 对）**：`docs/index`、`IMPLEMENTATION_STATUS`、guides（9）、
  evaluations（8）、ADR（README + 0002–0008）、reading-guide 等全部有 `.en.md`；
  `docs/BILINGUAL.md` 记录覆盖范围、不翻译清单（walkthrough / 内部过程稿）与 Phase 2 规则；
  `tests/test_bilingual_docs.py` 强制配对、互链、翻译声明与 mkdocs English 导航。
- **OpenAPI 3.1 离线示例**（@chaser940428-pixel，#179 / #166）：`examples/host_n_openapi31/`
  展示 `type: ["string","null"]`、`const`→`enum`、`$ref` 兄弟键覆盖；全离线、无 Key、无网络，
  附中英 README 与 2 项回归测试。
- **文档实测行修正**：`IMPLEMENTATION_STATUS` 更新到 **2 457 项收集 / 2 452 passed / 5 skipped、
  覆盖率 93.17%**；`ROADMAP` 头部与版本记录同步。

## 升级指引

- 无 breaking：纯文档、示例、模板与 CI 守卫；`dependencies = []` 不变。
- 新增英文文档不改变任何运行时行为；中文仍是权威版本。

## 验证

- 全量门禁通过（lint / mypy / 版本与打包守卫 / 全量测试+覆盖率 / 冒烟）；
- `mkdocs build` 通过，英文页已上线；双语文档守卫 4 项、docs 站链接守卫、sdist 链接完整性全绿；
- 新示例本地实跑输出正确（`note` 联合类型、`mode` enum、`limit` 最大值 3）；
- CI 四平台矩阵 + sdist + docs + fuzz + sidecar + benchmark 全绿。

## 明确边界

- `docs/walkthrough/`（57 章）与内部台账/方案/报告按约定不翻译（见 `docs/BILINGUAL.md`）；
- 剩余英文 backlog：`whitepaper.en.md`、`ROADMAP.en.md`、`CHANGELOG` 英文摘要；
- OpenAPI 示例只验证发现/schema 翻译/注册，不证明真实接口、鉴权或完整 2020-12 兼容性。

# v0.27.3 — 文档站与父子核设计

v0.27.3 是"门面 + 设计"批次：把仓库里的 130+ 篇文档变成可搜索的 Web 站点，并把下一阶段
的战略能力（有向父子核）先写成可评审的契约，再动代码。内核行为零变化。

## 重点

- **文档站上线**：mkdocs-material 从 `docs/` 构建，发布到 GitHub Pages
  （https://gi-tuu.github.io/yai-agent-core/ ）；PR 只验证构建、`main` 才部署；
  新增 `tests/test_docs_site.py` 守 nav 路径与"docs 内链接不逃出站点根"；
  本地过程稿（台账 / 方案 / 赛事材料）由 `exclude_docs` 挡在站点外。
- **文档链接站点化**：docs 内指向仓库根的 23 个相对链接改为绝对 GitHub URL，站点上不再 404。
- **有向父子核设计**：[ADR 0008](https://github.com/Gi-Tuu/yai-agent-core/blob/main/docs/adr/0008-directed-federation.md)
  + [协议 v1 设计稿](https://github.com/Gi-Tuu/yai-agent-core/blob/main/docs/guides/federation.md) ——
  产品生态里父核可调用子核、子核无路反调；联邦在宿主层实现，内核仍单 agent、零第三方依赖。
  **本版只有设计，实现从 v0.28 起。**

## 升级指引

- 无 breaking，无行为变化；纯文档 / 站点 / 设计。

## 验证

- 本地 `mkdocs build`：179 页、无 WARNING/ERROR；文档站三个入口实测 200。
- 2393 项测试收集、2388 passed / 5 skipped；内核行覆盖率 93.13%（门禁 90%）。
- 全量门禁通过（lint / mypy / 版本与打包守卫 / 全量测试 / 冒烟）；sdist 含新文档与 `mkdocs.yml`。
- CI 四平台矩阵 + docs build job 全绿。

## 明确边界

- 父子核尚未实现（Phase 1 起）；本版不得宣称"联邦可用"。
- 文档站只发布被 git 跟踪的公开文档；本机过程稿、构建产物（`exports/`）与赛事材料不出现。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

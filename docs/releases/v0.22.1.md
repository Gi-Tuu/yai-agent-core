## 四条主线

1. **执行语义：把"看起来安全"改成"实际安全"**
   - 模型吐出坏 JSON 时按 `{}` 处理，等于把一次模型错误升级成一次"成功"的空参调用；
     现在 Anthropic 与 OpenAI 兼容层在 parse 边界直接拒绝。
   - 幂等缓存命中直接回放，等于把首次调用时的权限当成"现在仍然成立"；现在缓存条目同时记录
     首次调用的权限依赖（含组合工具的嵌套子调用），重放前逐个复核当前准入——只复核、不审批、不执行。
   - 组合工具把剩余 timeout 预算下发给每个步骤：同步 handler 在事件循环线程里直接跑，
     外包超时根本没机会触发，声明的 50ms 曾等同"跑完 0.4s 还报成功"。
   - OpenAPI 路径拒绝独立 `.` / `..` 段（`quote(safe="")` 保留 `.`，挡不住 httpx 的点段规范化）。

2. **取消与超时：Python 3.11 上的一个真缺陷**
   3.11 的 `asyncio.wait_for` 在"内层协程恰好完成"时会走 `if fut.done(): return fut.result()`，
   **把外层 `CancelledError` 吞掉并返回结果**。内核的委派链路恰恰靠取消生效
   （"一个子任务失败要中断另一个子任务"就是 `task.cancel()`）——取消一被吞，在飞的工具没人中断，
   整次委派挂死。CI 在 3.11 上稳定复现，3.12 / 3.13 正常。
   现把内核与 `shell/employee` 路径上所有"包住内联 await 的超时"统一换成 `asyncio.timeout`
   （3.11+ 都有，且与 3.12+ 的 `wait_for` 是同一套语义），覆盖 10 个文件。
   回归用例用 `call_soon` 把取消精确打在"模型调用刚返回"的竞态窗口上；**去掉内核改动即必红**。

3. **数据与状态：坏路径不再留在原地**
   - SQLite 备份 / 恢复改为"同目录暂存 → 校验 → 关闭连接 → 单文件 `os.replace`"，
     失败保留旧目标；绝不再先删 `-wal` / `-shm` 再发现源不能用。
   - 子员工权限逐层叠加父级当前策略（两层都 ALLOW 才执行），父级运行期撤权立即生效；
     失败按执行器真实返回值回流，不靠模型措辞判断。
   - `AgentCore` 关闭后再 `astream` 直接报 `RuntimeError`，不再静默走空循环。

4. **打包与供应链：发出去的包要自己说得清**
   - sdist 包内文档断链 **12 → 0**（白皮书 9 张赛事配图、部署文档 2 处、ROADMAP 1 处），
     并新增 `tests/test_sdist_link_integrity.py`（19 例）钉住。
   - `publish.yml` 导出并上传 `dist/provenance/*.intoto.jsonl`——Scorecard 的 Signed-Releases
     检查只认作为 Release 资产上传的 attestation。
   - sidecar 补上服务端端到端测试（29 例），五个模块覆盖率 **全部 100%**。

# v0.36.0 — 机器可读冒烟（社区贡献）

v0.36.0 是社区贡献版本：`scripts/smoke_test.py` 增加 `--json`，让 CI / 巡检脚本不用解析
面向人的日志。同时修正了一处一直停在 v0.33.0 的文档实测行。

## 重点

- **`scripts/smoke_test.py --json`**（@chaser940428-pixel，#174 / #167）：
  - stdout 只输出一个 `{"ok": ..., "checks": [{"name": ..., "ok": ...}]}`；
  - 每个 `checks` 项带稳定宿主名；失败项另有 `error`；
  - **一个宿主失败仍继续检查另一个**，最后统一判定；全部成功退出 0，任一失败退出 1；
  - 默认文本模式输出、异常抛出与 Core 关闭规则完全不变；不新增依赖。
- **文档实测行修正**：`docs/IMPLEMENTATION_STATUS.md` 的"当前 HEAD 实测"从
  v0.33.0 / 2 442 项更新为 v0.36.0 / 2 451 项（2 446 passed、5 skipped、覆盖率 93.15%）。

## 验证

- 新增 4 项回归（成功单对象、工具失败隔离、CLI 成功/失败退出码与纯 JSON stdout）；
- 本机 Windows：`smoke_test.py --json` 可被 `json.tool` 解析、默认模式行为不变、
  定向测试 27 passed、全量门禁通过（2451 项收集）；
- CI：四平台矩阵 + sdist + docs + fuzz + sidecar + benchmark 全绿（首次贡献者 workflow 经维护者批准）。

## 明确边界

- `--json` 只覆盖离线两宿主冒烟（笔记 / 陪伴），不代表业务语义评测；
- 宿主事件/警告仍可能写 stderr（stdout 保持纯 JSON）；
- 网络、真实模型、真实桌面行为不在该脚本范围内。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

# v0.62.3 — 幂等重放拆分

> **English summary**: v0.62.3 is a patch on the 0.62 line. It moves the idempotent cache lookup,
> permission recheck and replay TOOL_RESULT into `tools/cache_lookup.py`; `executor.py` is now 47.8KB.

v0.62.3 继续 0.62.X 结构重构线。

## 1. 幂等重放状态对象

新增 `src/yai_core/tools/cache_lookup.py`：

- `_CacheLookup`：一次查找的 key / fingerprint / 命中结果；
- `lookup_cache(executor, ...)`：
  - 生成幂等键并取 fingerprint；
  - 命中时复核当前策略 DENY 与缓存依赖；
  - 生成 replayed 收据与 `TOOL_RESULT`；
  - 参数冲突 / 权限撤权 / 依赖失效都失败关闭。

`ToolExecutor._lookup_cache` 只做参数转发。

`tools/executor.py` 50.7KB → **47.8KB**。

## 2. 兼容性

- 行为不变：缓存命中、重放、拒绝路径与事件顺序保持一致；
- `_IdempotencyError` 移到 `tools/idempotency.py`，`executor` 旧引用仍可用；
- 收据链与 `replayed` 字段不变。

## 3. 验证

- 全量门禁：2,550 项 / 2,545 passed / 5 skipped / 92.97%；
- execution receipts / boundaries / loop 回归通过；
- sdist 打包测试通过。

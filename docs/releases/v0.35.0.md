# v0.35.0 — 灵动岛跨核可视化

> **English summary**: Cross-core calls visualized in the Dynamic Island panel; lazy desktop package exports.

v0.35.0 把父子核的**跨核调用接进灵动岛面板**：专员作为父核调用子核时，面板显示
`CROSS-CORE` 摘要（调用 / 失败 / tokens）。同时让桌面包惰性导出，纯逻辑在没装 PySide6 的
CI 里也能测；并播下 5 个 good-first-issue。

## 重点

- **`shell/desktop/federation_view.py`**：从 `tool_call` / `tool_result` 识别
  `prefix__tool` 形态的跨核调用，按 edge 聚合调用数 / 失败数 / tokens（子核回报 `usage` 时）/
  最近工具与结果；纯 Python，不依赖 Qt。
- **`WorkbenchRuntime`**：新增 `crossCoreEdges`（QVariantList，`crossCoreChanged` 通知），
  `_relay()` 统一喂视图；QML 只读聚合属性。
- **`Panel.qml`**：专员切换条下方渲染 `CROSS-CORE` 摘要（如 `notes·1 18t`），失败变红，
  无跨核调用时不占高度；销售演示脚本增加一次对笔记子核的委托，离线演示即可看到。
- **惰性导出**：`shell/desktop/__init__.py` 改为 PEP 562 惰性导出，`federation_view` 可在
  无 PySide6 环境导入（CI 无 `[desktop]` extra 也能跑聚合逻辑测试）。
- **good-first-issue 种子**（GitHub #166–#170）：OpenAPI 3.1 可运行示例、`smoke_test.py --json`、
  Go MCP 示例、CROSS-CORE 离屏 QML 测试、CONTRIBUTING 真机章节。

## 升级指引

- 无 breaking：QML 新增只读属性；桌面包导出方式改为惰性（`from shell.desktop import X` 行为不变）。

## 验证

- 新增 `tests/test_desktop_cross_core.py` 5 例（解析 / 聚合 / 过滤 / usage / 工作台接线）；
- `pyside6-qmllint Panel.qml` 通过；全量门禁通过（2447 项收集）。
- 演示脚本离线可复现：销售专员任务中出现 `notes__add_note`，面板横条出现 `notes·1 18t`。

## 明确边界

- 面板只做可视化，不改变路由 / 预算；`max_tokens` 预算仍由父核 `Federation` 执行。
- 演示里的跨核调用是**演示事件**（不是真实子进程联邦）；真实联邦事件同样进入该视图。
- QML 层仍只有 `qmllint`，离屏交互测试属于 #169 的 good-first 任务。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

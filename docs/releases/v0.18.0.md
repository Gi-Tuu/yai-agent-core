## 一、桌面陪伴专员：最近心情作为现状锚

`shell/desktop/host.py` 的 `_live_factory` 新增可选参数：

```python
state_provider=("companion", lambda: _companion_state(companion_host))
```

- 每次任务新建 Core 时注册 `companion` 状态源；
- 内容为**最近 3 条心情 + 总记录数**；
- 模型每次调用前瞬态注入，不写入对话历史、长期记忆或压缩摘要；
- 任务结束随 Core 一起释放，不会跨专员串状态。

以前模型回答“我现在心情怎么样”需要先调 `mood_trend`；现在可以直接看到当前状态，
同时工具仍然保留、仍受权限与审批约束。

# v0.32.0 — 互操作批次

> **English summary**: GHCR image, typed Node/TS sidecar client, and OpenAPI 3.1 / JSON Schema 2020-12 compatibility.

v0.32.0 补齐三件互操作能力：**OpenAPI 3.1 / JSON Schema 2020-12** 兼容、
**类型化 Node/TS sidecar 客户端**、**GHCR 容器镜像**。内核依赖与公开契约不变。

## 重点

- **OpenAPI 3.1 / 2020-12**：接受 `openapi: 3.1.x`；`type` 联合中的 null 原样保留、
  `const` 归一为单值 `enum`、`$ref` 兄弟键覆盖目标、数值型 `exclusiveMinimum/Maximum` 保留；
  `prefixItems` / `if-then-else` / `patternProperties` / `webhooks` / 路径级 `servers` 等
  未翻译构造**只记 notes，不拒绝整份描述**。矩阵见
  [docs/guides/openapi-31-compat.md](https://github.com/Gi-Tuu/yai-agent-core/blob/main/docs/guides/openapi-31-compat.md)。
- **类型化 Node/TS 客户端**（`clients/node/`，零运行时依赖，Node ≥ 20）：
  `initialize` / `run` / `cancel` / `ping` / `shutdown`、`onEvent` / `waitForEvent`、
  审批/澄清回调（**默认拒绝**，失败关闭）、退出/超时映射为 `SidecarError`；
  假 sidecar fixture 的 5 项 `node --test`；CI `Node client` 工作流。
- **GHCR 镜像**：`docker.yml` 在 tag `v*` 推送时构建发布 `ghcr.io/gi-tuu/yai-agent-core`
  （semver + latest，provenance + SBOM）；PR 只验证构建。

## 升级指引

- 无 breaking：新增能力与客户端；内核依赖仍为空。

## 验证

- 全量门禁通过；OpenAPI 3.1 兼容 10 例、TS 客户端 5 例、schema 回归全绿。
- CI 额外跑 `Node client`（npm ci + test）与 `Docker image`（构建，不推送）两个工作流。
- 容器运行方式见 `docs/guides/demo-deployment.md` §3.5。

## 明确边界

- 2020-12 只翻译工具入参所需子集；未翻译构造不强制、也不喂给模型（矩阵内逐项列明）。
- TS 客户端只覆盖会话面；工具面仍走 MCP / OpenAPI。
- 镜像不含 `[desktop]` / `[browser]` / `[windows]` 依赖；本机 Docker daemon 未启动，
  镜像构建以 CI 结果为准。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

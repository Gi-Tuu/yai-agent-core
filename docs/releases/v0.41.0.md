# v0.41.0 — 真实 CopilotKit 前端 demo

> **English summary**: v0.41.0 ships a real CopilotKit v2 frontend demo
> (`examples/host_ag_ui_copilotkit/`). The browser talks to CopilotKit Runtime, which proxies
> runs through `HttpAgent` to YAI's FastAPI `/agent` (AG-UI SSE). Verified end-to-end locally:
> CopilotChat renders the reply and the event panel shows `RUN_STARTED / TEXT_MESSAGE_* /
> RUN_FINISHED`. Screenshot: `docs/assets/copilotkit-demo.png`.

v0.41.0 把 AG-UI 适配器从"协议示例"推到"真实前端"：用 **CopilotKit v2** 渲染 YAI 的 SSE 事件流。

## 重点

- **架构**：
  ```
  浏览器 CopilotChat
    → CopilotKit Runtime /api/copilotkit（CopilotRuntime + createCopilotEndpointExpress）
    → HttpAgent
    → YAI FastAPI /agent（本仓库 examples/host_ag_ui_sse）
  ```
- **示例**：`examples/host_ag_ui_copilotkit/`（Node server.mjs、Vite + React、`CopilotKitProvider`
  + `CopilotChat`、右侧 AG-UI 事件面板、中英 README、package-lock）。
- **本机实测（2026-11-14，Node 24 / CopilotKit 1.87.1 / Chromium）**：
  - `/api/copilotkit/info` 返回 `mode: sse`、agent `default`；
  - 发送「你好，介绍一下你自己」→ 回复「AG-UI demo：收到…」；
  - 事件面板出现 `RUN_STARTED / TEXT_MESSAGE_START / TEXT_MESSAGE_END / RUN_FINISHED`；
  - 截图 [`docs/assets/copilotkit-demo.png`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/docs/assets/copilotkit-demo.png)。
- **文档**：`docs/guides/ag-ui.md` / `.en.md` 新增第 7 节、README 示例表第 14 行、
  IMPLEMENTATION_STATUS、CHANGELOG；sdist 增加 `/docs/assets`。

## 升级指引

- 无 breaking：只新增示例与文档；Python 内核依赖仍为空。
- 运行：先起 YAI AG-UI 后端（`uv run uvicorn examples.host_ag_ui_sse.app:app --port 8000`），
  再 `cd examples/host_ag_ui_copilotkit && npm install && npm run build && npm start`。

## 明确边界

- 单用户本地 demo（固定 `identifyUser`）、离线 `ScriptedModel`；
- 未接 Copilot Cloud / 生产鉴权 / 多租户；
- Node 依赖不进入 Python 包，CI 不构建前端（本机验证并留截图）；
- 前端 bundle 较大（CopilotKit UI 自带高亮/Mermaid 等），仅 demo 用途。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

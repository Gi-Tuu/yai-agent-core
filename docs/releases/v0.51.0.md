# v0.51.0 — A2A PKCE + worker flake

> **English summary**: v0.51.0 adds PKCE S256 and state validation to the A2A authorization-code
> flow, and fixes the desktop worker-loop flake with a loop-readiness event plus wider drain/test
> timeouts. Three new good-first issues (#220–#222) were opened; Registry signatures remain pending
> a v0 spec field.

v0.51.0 做两件收尾：把 authorization-code 补到生产级（PKCE + state），并把 desktop worker-loop
偶发压掉。

## 1. A2A PKCE + state

- `authorization_url(state)` 默认生成 PKCE S256 challenge，并保存 verifier；
- `exchange_code(code, state=...)`：
  - state 与生成时不一致 → 直接拒绝；
  - 带 `code_verifier` 换 token；
  - 换完清空一次性 state/verifier；
- 兼容 `use_pkce=False`；11 例 A2A 离线测试覆盖 URL/challenge/state mismatch/换 token。

## 2. desktop worker-loop 偶发

- `WorkbenchRuntime` 新增 `_loop_ready` 事件；提交学习/工具仓库任务前最多等 2s；
- `shutdown` drain 超时 3s → 5s；
- 测试 `_pump` 默认 5s → 15s；
- 全量门禁通过，单测 30 次压力无失败。

## 3. 新一轮 good-first issue

已关闭 #168/#169/#170（均已合并），新开：

- **#220** Java 宿主经 MCP 接入的最小示例；
- **#221** SettingsPopover 离屏 QML 交互断言；
- **#222** AG-UI 事件映射 Mermaid 时序图。

## 4. Registry 签名

保持观察：v0 无统一签名字段；digest pin + `verify_entry` 钩子不变，不伪造签名格式。

## 验证

- 全量门禁：2,523 项 / 2,518 passed / 5 skipped，覆盖率 93.09%；
- A2A 11 例、desktop 17 例通过；CI 四平台全绿。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

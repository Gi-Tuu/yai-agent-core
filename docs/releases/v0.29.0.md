# v0.29.0 — 有向父子核 Phase 2（本机 IPC）

> **English summary**: Federation Phase 2: local IPC between processes with discovery, tokens and grants.

v0.29.0 把"父核调子核"从同一进程推到**两个进程**：产品各自跑自己的核，父核通过本机 IPC
调用子核声明的工具；子核退出、grant 非法、超时一律失败关闭。内核依旧零改动。

## 重点

- **`ChildServer`（子核侧）**：绑定 `127.0.0.1` 随机端口，NDJSON + JSON-RPC 2.0；
  启动时写发现文件（protocol / node_id / child_id / host / port / token / pid，POSIX 0600）；
  握手校验协议版本 + token + 父核允许列表，随后签发**HMAC 签名的 grant**（密钥只在子核进程内）；
  `federation.tools.call` 逐次校验签名 / 过期 / 工具子集 / 子核身份。
- **`LinkChild`（父核侧）**：读发现文件 → 握手 → 长连接 + 请求多路复用；与进程内 `ChildCore`
  同形，`Federation.register_child()` 无需区分；错误映射为 `GrantDenied` / `ChildCallFailed` /
  `ChildUnavailable`。
- **跨进程环检测**：父核把调用链随请求下发，服务端注入执行上下文，A→B→A 这类跨进程环同样被拒。
- **失败关闭**：子核退出后再连 → `ChildUnavailable`；token 错 / 父核不在允许列表 → 握手拒绝；
  deadline 超时 → 工具失败回流，不挂死父核。
- **示例**：`examples/host_m_federation/child_app.py`（文档子核服务）+ `ipc_demo.py`
  （拉起子进程 → 调用 → 健康检查 → 杀进程验证失败关闭）。
- **测试**：`tests/test_federation_ipc.py` 7 例；联邦测试合计 19 例。

## 升级指引

- 无 breaking：新增宿主层模块；内核依赖仍为空，公开契约不变。
- 安全边界照实声明：同 OS 用户前提；发现文件权限与 token 只防同机其他用户/进程，
  **不防 root / 调试器 / 内存抓取**。

## 验证

- 2412 项测试收集、2407 passed / 5 skipped；内核行覆盖率 93.13%（门禁 90%）。
- 双进程 demo 实跑：连上子核 → 调用成功 → 健康检查 → 杀进程后再连失败（`ChildUnavailable`）。
- 全量门禁通过；CI 四平台矩阵 + docs build 全绿。

## 明确边界（Phase 3 起）

manifest 热更新、常驻子核生命周期托管、每 edge 配额、预算跨核聚合、跨核事务、
断线自动重连与 grant 重签均未实现；不做对等 Multi-Agent。

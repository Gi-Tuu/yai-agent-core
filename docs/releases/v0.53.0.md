# v0.53.0 — FastAPI 会话隔离 + Federation subject 绑定

> **English summary**: v0.53.0 adds per-session FastAPI cores (`session_id` +
> `core_factory`, LRU pool, scoped example memory) and binds the federation handshake
> `subject` into the signed grant so calls cannot switch identity on the same grant.

v0.53.0 完成审计里剩下的两项 P1/P2 安全债：API 多租户会话隔离、Federation subject 绑定。

## 1. FastAPI 会话隔离

- `RunRequest` 新增 `session_id`；
- `create_app(core_factory=..., max_sessions=64)`：
  - 按 `session_id` 惰性创建独立 `AgentCore`；
  - LRU 复用；超上限淘汰并 `aclose` core + 关闭 memory；
  - 关闭时清空全部会话；
- 单 core 模式传 `session_id` → 400（避免“看似隔离”的假安全）；
- 多会话模式缺 `session_id` / 非法 id → 400；
- `scripts/serve_example.py` 按 session 建独立 InMemory 或 `SqliteStore(scope=...)`，
  并把启动后挂载的 native/MCP/OpenAPI 工具面复制到新 core。

## 2. Federation subject 绑定

- 握手新增 `subject`，并签入 HMAC grant payload；
- `tools.call` 必须与 grant 的绑定 subject 一致；
- 未绑定 subject 的 grant 拒绝携带 subject 的调用；
- 父核 `_invoke` 默认使用注册 grant 的 subject，同一 grant 换主体直接拒绝；
- `LinkChild.connect` / `ManagedChild` 支持 subject。

## 3. 验证

- 全量门禁：2,541 项 / 2,536 passed / 5 skipped，覆盖率 92.99%；
- 新增 API 会话隔离 4 例、Federation subject 1 例；
- 原有 A2A / Registry / MCP / Desktop / Sidecar 回归保持通过。

## 4. 边界

- 会话池仍是进程内 LRU，不跨进程共享；SQLite 用 `scope` 复用库文件；
- 单 core 模式仍支持本地单租户，不支持多租户；
- Federation subject 只在 `ManagedChild`/`LinkChild` 握手中生效；进程内 `ChildCore`
  仍由宿主代码直接传 subject（无握手）。
- Rate limit 的 XFF 信任、composite 超时事件、DONE 内链式 run 死锁仍是后续项。

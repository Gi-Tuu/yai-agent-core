# YAI Agent Core v0.26.0

> 2026-11-03 · 执行能力成为可选适配器，同时把"能验证"落到工程链路里。

## 三条主线

1. **可选执行适配器**：Browser Provider（快照引用 / 来源闸 / 统一治理 / 旧引用过期）、
   Windows Desktop Provider（UIA 语义优先 / 焦点保护 / 用户接管 / 高风险拒绝），
   全部独立可选、按需挂载，内核仍 `dependencies = []`。
2. **可验证结果**：Outcome Verification 契约把"工具执行收据"与"任务目标达成"分开；
   `Evidence` / `VerificationResult` / `OutcomeVerifier` 由宿主提供，验收失败只降级
   `not_verifiable`，不重试、不改最终文本。
3. **宿主接入**：浏览器扩展 MV3 Side Panel + Native Messaging Bridge，真实 Edge
   端到端任务（Bridge → Sidecar → MCP 浏览器工具）；CDP 模式可接管本机 Chrome；
   面板支持 LLM 配置（Key 只写本机、读回脱敏）、审批/澄清、运行态恢复与取消。

## 本版工程数字（2026-11-03 实测）

## 升级与兼容

- 版本 `0.25.0 → 0.26.0`；公开事件仍 21 类，新增字段均为加性
  （`RunResult.status/error`、`DONE.status/error`）。
- 预算 `model_calls` 口径改为"已发起尝试"（失败/超时计入、被熔断拒绝不计），
  与 `DONE.model_calls` 一致。
- MemoryVault：读路径不再因 touch 落盘失败而失败；owner 未声明遇已声明文件 →
  只读；保存绝不抹除 owner；多实例/多进程写入按外部修改检测 + 锁合并。
- 浏览器/桌面适配器需安装对应 extras；扩展需重新加载，Native Bridge 需用
  `scripts/register_native_host.py` 重新注册/重打包冻结 exe。
- 面板修改 Base URL 时必须同时提供新 API Key（有意行为）。

## 诚实边界

- 真实鼠标点工具栏图标、安装包分发仍需人工验收。
- 真实浏览器仅一次本机冒烟；嵌套 frame、下载/上传/CAPTCHA、真实站点多样性、
  视觉定位未验证。
- 桌面 Provider 仅自建 WinForms 冒烟；第三方应用、截图、UAC 提权窗口未验证。
- 文件锁为 advisory；宿主 verifier 自返回的 evidence 不套内核证据上限。
- 真实模型只做抽样验证，CI 全部使用脚本模型。

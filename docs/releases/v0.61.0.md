# v0.61.0 — Native Bridge 拆分

> **English summary**: v0.61.0 moves bridge errors and Native Messaging framing/truncation out of
> `native_bridge.py` into `bridge_errors.py` and `framing.py`, with compatibility re-exports.

v0.61.0 继续结构拆分；行为、帧格式、截断策略不变。

## 1. 拆分结果

`src/yai_core/sidecar/native_bridge.py`：50.1KB → **44.9KB**

- `src/yai_core/sidecar/bridge_errors.py`：`BridgeError` / `BridgeOriginError`；
- `src/yai_core/sidecar/framing.py`：
  - Native Messaging 4 字节小端帧编解码；
  - `MAX_MESSAGE_BYTES` / `TRUNCATED_*` 常量；
  - `build_truncated_message` 超帧截断。

## 2. 兼容性

```python
from yai_core.sidecar.native_bridge import (
    BridgeError, BridgeOriginError, encode_frame, read_frame,
    build_truncated_message,
)
```

以上路径仍可用；实现位置变化不影响行为。

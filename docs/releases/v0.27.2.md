# v0.27.2 — 首屏可跑 + 浏览器告警对齐

> **English summary**: Zero-key QuickStart, a reworked README first screen, and browser/desktop warning parity.

v0.27.2 是采用面补丁：把"第一次成功"压到 30 秒，并补齐浏览器侧与桌面侧的安全告警对称性。

## 重点

- **首屏即跑通**：中英 README 把「30 秒跑起来」提到截图之后、能力表之前；零 Key（ScriptedModel）
  先看到工具被调用，再换一行接真实模型。
- **可执行的 QuickStart**：`examples/quickstart.py` 把两个普通函数交给内核 → 自动内省成工具 →
  事件流打印路由 / 工具调用 / 完成；`tests/test_quickstart_example.py` 用子进程真实执行，
  保证 README 第一屏的承诺不会腐烂。
- **告警与桌面对称**：`BrowserProvider` 现在对"显式传入但来源不受限"（`allowed_origins` 为空或含
  `*`）的策略也发 `BrowserSecurityWarning`；新增 `BrowserPolicy.origins_unrestricted` 只看来源口径，
  `is_permissive` 保持"来源不受限 + 未配审批"的旧语义并在文档写明区别。

## 升级指引

- 无 breaking。唯一行为变化：显式传入宽松 `BrowserPolicy` 时会多一条警告。若你的测试断言
  "显式传入即无警告"，请放宽为"来源受限才无警告"。

## 验证

- 2390 项测试收集、2385 passed / 5 skipped；内核行覆盖率 93.13%（门禁 90%）。
- 全量门禁通过（lint / mypy / 版本与打包守卫 / 全量测试 / 两宿主冒烟）；sdist 链接完整性 19 例。
- QuickStart 示例在 Linux 3.11/3.12/3.13 与 Windows 3.13 的 CI 里全部真实执行通过。

## 明确边界

- 本版不改执行语义、不扩大任何适配器能力；浏览器 / 桌面真机矩阵与 v0.27.1 相同。
- README 里的演示视频 / GIF 尚未录制，当前以文本输出演示。

完整逐条变更见 [`CHANGELOG.md`](https://github.com/Gi-Tuu/yai-agent-core/blob/main/CHANGELOG.md)。

sherlock 原本是命令行工具：你得装它、记参数、读 JSON 输出。

$ pip install sherlock-project
$ sherlock torvalds --limit 10
[+] Checking 10 sites...
9GAG: https://9gag.com/u/torvalds
[*] Done. Results saved to torvalds.txt
↑ 你得自己理解输出格式、自己决定下一步做什么

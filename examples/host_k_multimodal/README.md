# host_k_multimodal —— 多模态消息 + 宿主侧资源引用解析

> 这个示例回答一个具体问题：**消息里带图片、带"文件引用"时，谁负责什么？**

## 一句话口径

| 谁 | 负责什么 |
|---|---|
| **模型** | 只能**选句柄**（`res://note/1`），不能决定自己能看到什么 |
| **宿主** | 解析句柄、判作用域、判有效期、判大小——**授权与生命周期都在宿主** |
| **内核** | 只负责把片段带进消息链路、渲染占位、计预算；**不抓取任何外部资源** |

## 跑一遍（离线，不需要 Key）

```bash
python examples/host_k_multimodal/run.py
```

输出会演示：模型读 `res://note/1` → 宿主解析 → 文本回灌 → 模型据此回答；
事件时间线里能看到 `tool_call` / `tool_result`。

## 三条边界

1. **模型改不了自己的作用域**：它能选的只是句柄；作用域判定用的是宿主自己的
   `allowed_scopes`（示例里是 `tenant:a`），换成 `tenant:b` 的资源会被拒。
2. **过期由宿主判**：内核没有"时钟真相"，`expires_at` 只是随引用带过来的声明，
   由宿主在自己的时钟上判定。
3. **路径仍走内核那套纯函数**：`normalize_relative` + `resolve_within_root`，
   与文件能力后端**同一套语义**——避免"闸门认的路径"和"实际读的路径"不是一回事。

## 与内核多模态契约的关系

- `ImagePart(data=...)`：**内联**，模型**真的看得见**（出站是 OpenAI 兼容的内容数组，
  Anthropic 后端会被翻译成 Claude 的 image 块）。
- `ResourcePart(uri=..., scope=..., expires_at=...)`：**引用**，模型看不到内容，
  只会看到一句"内容由宿主提供，内核未内联"——**绝不静默丢**。
- 落盘只存引用与元数据，**不存图片字节**。
- 后端不支持多模态时（没声明 `yai_multimodal`），片段自动降级成纯文本占位。
